# Copilot Instructions

## Design Guide

When making visual or UI changes in this repository, follow these guidelines:

- Keep changes small and focused; prioritize usability and readability over decorative detail.
- Use the existing page structure and HTMX flow rather than adding new JavaScript frameworks.
- Prefer system sans-serif fonts or local font stacks; avoid importing large external font families unless explicitly requested.
- Use subtle gradients, soft shadows, and rounded surfaces for a modern, polished aesthetic.
- Maintain accessible contrast and clear interactive states for buttons, cards, and tiles.
- Align frontend updates with existing templates in `app/templates/` and shared styles in `app/static/css/app.css`.
- Avoid changing application logic unless a design change requires a small, deliberate bug fix.
